# HARP Electrical & Heat Pumps website

A rebuild of the website for HARP Electrical & Heat Pumps, an electrician and Mitsubishi
Electric approved heat pump installer based in **Amberley**, North Canterbury, serving the
Hurunui and Waimakariri districts.

Static HTML/CSS/JS, no build step. Open `index.html` in a browser to preview.

## Files
- `index.html`: homepage (hero, trust strip, services, accreditation, areas, reviews, FAQ, contact form)
- `services/`: one page per service
- `areas/`: local landing pages, Hurunui first then Waimakariri
- `about.html` / `finance.html`: company story and Q Card finance
- `css/styles.css`: all the styling
- `js/main.js`: mobile menu, footer year, contact-form AJAX + thank-you popup
- `robots.txt` / `sitemap.xml`: help Google find the pages

## Status
Not live. This is a rebuild to show Harp. Their existing site at harpelectrical.co.nz is
untouched, and no DNS has been changed.

## Editing rule
Every change gets a dated entry in `CHANGELOG.md`, then a commit, so the repo is always a
clear record of what changed and why.
